# Nvim Config
this is my nvim config 

## Features
### Theme
    - catppuccin

### Plugins
    - neoGit -- provides git Integration into nvim
    - lualine 
    - telescope -- searches active directory for project files
    - whichkey -- shows avalible commands
    - orgmode -- enables orgmode in nvim
    - oil.nvim -- file manageman

### LSP Integration
    - blink.cmp -- code completion
    - conform -- formats files
    - fidget -- get lsp messages
    - nvim-lint -- implemets linters
    - nvim-lspconfig -- enables lsp support into nvim
    - mason - mason-tool-installer - mason-lspconfig -- downloads formaters, linters and lsps 


## Installation

### Standard Installation
to install the config on a standard linux distro clone the this repo into you neovim config directory
this is usually the ~/.config/nvim
```bash
    git push https://github.com/MothMan665/nvim.git
```
